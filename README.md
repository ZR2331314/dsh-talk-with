# 剧情向多人格插件（dsh-talk-with）

同一个 DSH 窗口里，按**称呼**切换人格，也可以让几位同台接话；每个人格自带正文与头像，头像下方显示人格名；剧情阶段推进时，头像按阶段自动替换。

```text
「莉莉，帮我看看这段日志」   → 这一句起换成莉莉
「琳恩，刚才那个再说一遍」     → 这一句起换成琳恩
「那这份文件呢」               → 沿用上一个（不会乱切）
```

---

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 按称呼切换 | 消息里叫到别名即切换；没叫到就沿用当前人格 |
| 多角色同台 | 一轮点 ≥2 位，按点名顺序各说一段，共用同一段记忆 |
| 头像 + 名字 | 每条消息贴回当时说话的人格头像，头像下方显示人格名 |
| 同台分段头像 | 一条消息里按「【名字】」分节，每节各贴各的头像 |
| 剧情阶段头像 | 面板选阶段 / 传阶段图，或剧情中输出 `{{stage:阶段id}}` 自动切换 |
| 历史贴脸 | 不同轮次按当时人格贴回头像；同台轮次按段序对位 |

## 人格 = 一个文件夹

人格目录：`<DSH_HOME>/personas/<人格id>/`

```
personas/lili/
  persona.json    人格配置（name、aliases、color、stages…）
  prompt.md       人格正文
  lore.json       世界书（可选，关键词命中注入）
  avatar.png      默认头像（也认 .jpg/.jpeg/.webp）
  stage-evolved.png  阶段头像（配合 stages 声明）
```

面板（设置 → 剧情向多人格插件）里可以改名、改别名、启用/停用、设默认、换头像、选阶段、传阶段图。

## 剧情阶段头像

1. `persona.json` 声明阶段：`"stages": [{ "id": "evolved", "name": "进化·大哥布林" }]`
2. 阶段图命名为 `stage-<阶段id>.png` 放进同一目录
3. 切换方式三选一：
   - 面板「阶段」下拉选中即切
   - 剧情中模型输出 `{{stage:evolved}}`（落在该轮说话的人格）或 `{{stage:evolved:lili}}`（显式指定）；标记不会显示在消息里
   - API：`POST /persona-router/stage`，body `{"persona":"lili","stage":"evolved"}`；stage 空串回到默认头像

切换后 1.5 秒内界面自动换图，历史消息随当前阶段一起换（不回放旧阶段）。

## 同台规则

- 一轮点 ≥2 位 ⇒ 同台：先被叫到的先开口，其余按点名顺序接话
- 每人一段，段首用「【名字】」单独起一行；后开口的要指明回应前一位的哪一句
- 判定只认称呼位，正文中间顺带提到的名字不算
- 同台后由先开口那位接棒：下一轮不带名字继续跟她聊

## 配置

`<DSH_HOME>/persona-router/config.json`：

| 键 | 说明 |
| --- | --- |
| `enabled` | 总开关 |
| `multiRole` | 同台开关（默认开） |
| `pinLeadOnMulti` | 同台后先开口者接棒（默认开） |
| `avatarRepeatRows` | 长会话里头像间隔重复的行数（默认 6） |
| `avatarSize` | 头像尺寸 24–72px（默认 40） |

## 目录速查

| 用途 | 路径 |
| --- | --- |
| 人格目录 | `<DSH_HOME>/personas/` |
| 状态 | `<DSH_HOME>/persona-router/state.json` |
| 配置 | `<DSH_HOME>/persona-router/config.json` |
| 判定日志 | `<DSH_HOME>/persona-router/decisions.log` |

## 常见问题

- **上传头像报 EPERM**：图片带只读属性（从附件复制来的图常见），取消文件只读属性即可
- **改了 persona.json / 头像文件**：最多 1.5 秒自动生效，不用重启
- **同台几段挤在一条消息里**：模型一次输出就是一条消息，插件会按「【名字】」分节给每节贴各自的头像；模型未分段输出时只贴主答
